Lumen Drift is a neon arcade game: fly a skiff through a night sky, gather falling light,
bank it at the beacon, and dodge the storm shards. Carrying more light raises the bank
multiplier, but a hit spills half of it — bank early or risk it all. Bank 600 light to
light the beacon and win; lose all three lives and the light fades. Levels rise every 25
seconds, shards get faster, and a dash shatters them. Keyboard (WASD/arrows + Space) or
mouse, with synthesized sound, pause and a best score that persists between visits.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
